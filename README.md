# IMÁGENES Y SEÑALES DEL PERMISO DE CONDUCIR B
Este repositorio se compone de dos archivos pdf.
- Imagenes y señales para recortar.pdf
- Nombres de las imagenes y señales.pdf
En el primer archivo estarán todas las imágenes de forma que se puedan imprimir y recortarlas para no tener que recurrir a dibujarlas en apuntes o fichas

En el segundo archivo están todas las imágenes, pero con sus nombres debajo para que sean más sencillas de buscar y/o identificar
